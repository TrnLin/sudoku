## 2. Report Requirements

### 2.1 Format Specifications

- **Maximum length:** 20 pages

### 2.2 Report Structure

#### 1. Introduction

- Problem Specification
- Purpose
- Scope
  - Input Specification
  - Limitations

#### 2. System Design

- System Overview (start to finish)
- **Java Classes:**
  - Key classes explanation
  - Attributes and responsibilities
  - Class hierarchy/relationships
- **Methods:**
  - Names
  - Roles
  - Interactions
- **Design Patterns:**
  - Pattern identification and justification
  - Contribution to system functionality/maintainability

#### 3. Data Structures & Algorithms

- **Data Structures:**
  - Problem-specific structures
    - Visual representations
  - Performance testing structures
- **Algorithms:**
  - Algorithm selection
  - Detailed explanation

#### 4. Complexity Analysis

- **Time Complexity:**
  - Best case
  - Average case
  - Worst case
  - O notation for each function
- **Space Complexity:**
  - Per Thread complexity
  - Total Space complexity
  - Worst case analysis

#### 5. Evaluation

- **Test Setup:**
  - Environment
    - System specifications
    - JRE Version
  - **Testing Tools:**
    - Time (System.currentTimeMillis())
    - Memory (Runtime.getRuntime())
    - Correctness (95% confidence interval of 0.05 seconds)
  - Input Data sets
- **Metrics:**
  - Execution time
  - Memory usage
  - Correctness
- **Algorithm Comparison:**
  - Overall performance
  - Execution times
  - Runtime analysis
  - Memory usage patterns

#### 6. Conclusion

- Summary of Findings
- System Advantages
- System Limitations
- Future Work Recommendations
